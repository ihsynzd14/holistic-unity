# Outreach Templates — Holistic Unity

Copy-paste email templates for earning editorial backlinks. Replace `[…]` placeholders.
Keep the brand voice: calm, specific, honest — no hype. Send from a real person
(e.g. Marcello), not "marketing@". Personalise the first line every time (generic
blasts get ignored and can hurt sender reputation).

### Sending discipline
- Personalise line 1 (reference their actual content) — non-negotiable.
- ≤150 words. One clear ask. Real signature + link.
- Track replies; follow up **once** after ~5–7 days, then stop.
- Never buy links or use automated mass-mailers — for a YMYL site that's a penalty risk.
