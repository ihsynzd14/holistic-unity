# Backlink Playbook — Holistic Unity

Backlinks are the one SEO area that can't be fixed in code — they require other sites
to link to you. These assets do all the prep so the manual part is just submit/send.
(As of 2026-06-13 the site had ~1 real referring domain, and it was a nofollow auto-listing
— effectively 0. Everything else, on-page, is already strong: PageSpeed 99, valid schema,
hreflang, accessibility.)

| File | What it is | Your action |
|---|---|---|
| [practitioner-badge.html](practitioner-badge.html) | Embeddable "Operatore Verificato" badge (light/dark/text) linking to `/t/<slug>`. **Highest-leverage source.** | Wire into the operator dashboard (slug pre-filled) + email operators (template D). |
| [directory-submission-kit.md](directory-submission-kit.md) | 20+ vetted directories in 5 tiers + ready NAP + IT/EN descriptions. | Submit (copy-paste). Start Tier 1 + Tier 4. |
| [outreach-templates.md](outreach-templates.md) | IT/EN email templates (roundups, partnerships, press, operator badge). | Personalise line 1, send, follow up once. |
| [competitor-link-targets.md](competitor-link-targets.md) | Competitors + likely targets + the exact `backlink_opportunity` query to run tomorrow. | Re-run the query (free-tier quota resets daily), work the list with template A. |

## Suggested order
1. **Operator badge** → scales automatically with every onboarded operator.
2. **Directory Tier 1** (Google Business Profile, Trustpilot, App Store) + **Tier 4** (L.4/2013 associations).
3. **Social profiles** (Tier 5) — fast referring-domain wins.
4. **Re-run the SEO link-gap query** → outreach to the resulting domains.

## Don'ts (YMYL health-adjacent site)
No bought links, link farms, PBNs, or spammy directories — penalty risk far outweighs the gain.
Track **referring domains** monthly; expect slow, compounding growth over months.
